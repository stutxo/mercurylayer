# Security Policy

## Scope

This repository and the hosted wallet are research prototypes for Mutinynet.
They are not production wallets and must not be used with mainnet bitcoin or
funds that have real value. Only the latest commit on an active branch is
reviewed; historical tags and branches are unsupported.

## Reporting a vulnerability

Report sensitive vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/stutxo/mercurylayer/security/advisories/new).
Do not include exploit details, credentials, seed phrases, or private keys in a
public issue.

Include the affected commit and component, security impact, reproduction steps,
and any suggested mitigation. For non-sensitive bugs and documentation
problems, use [GitHub issues](https://github.com/stutxo/mercurylayer/issues).

This proof of concept has no bug-bounty program or guaranteed response time.
